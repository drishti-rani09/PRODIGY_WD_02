# Stopwatch Web Application

## About

This is a responsive Stopwatch Web Application developed as Task 2 of my Prodigy InfoTech Web Development Internship.

## Features

- Start the stopwatch
- Pause and resume the timer
- Reset the timer and clear lap records
- Record lap times
- Responsive design for mobile and desktop screens

## Technologies Used

- HTML
- CSS
- JavaScript
